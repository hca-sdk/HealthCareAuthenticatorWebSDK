# ONEKEY HCA SDK JS

ONEKEY HCA SDK JS is a javascript library to connect to OneKey HCA

## Build the library :

#### Install npm dependencies
- In a command prompt, run `npm install`

#### Launch webpack

- In a command prompt, run `npm install webpack`

- In a command prompt, run  `cd sdk-js`

- In a command prompt, run `npx webpack --config webpack.config.js`



the library is buit in the `/dist` directory.


## Sample site

See the documentation in the `.\sample-sdk-js` folder to configure and launch the demo site.
